\section{Template: Guida agli Stili e Box}
Questa sezione serve come riferimento per tutti gli elementi grafici e strutturali disponibili in questo progetto LaTeX. Copia e incolla da qui per mantenere la consistenza.

\subsection{1. Box per il Codice}
Utilizzare principalmente \texttt{jsbox} per snippet generici e \texttt{funcbox} per definizioni di funzioni importanti.

\subsubsection{JS Code Box (Standard)}
\begin{jsbox}
// Esempio di codice generico
const x = 10;
if (x > 5) {
    console.log("X è grande!");
}
\end{jsbox}

\subsubsection{Function Box (Per Funzioni)}
\begin{funcbox}[title={nomeFunzione}]
function nomeFunzione(param) {
    // Logica della funzione
    return param * 2;
}
\end{funcbox}

\subsection{2. Concetti e Definizioni}
Per definizioni teoriche, regole o concetti chiave, usare l'ambiente \texttt{concept}.

\begin{concept}{Titolo del Concetto}
Spiegazione teorica del concetto. Qui puoi scrivere testo normale, formule matematiche ($f(x) = x^2$) e enfatizzare parole in \textbf{grassetto}.
\end{concept}
